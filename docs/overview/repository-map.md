# Repository Map

The repository is organized around a Flask orchestrator, multiple agent engines, a React frontend, report rendering, evaluation harnesses, and runtime assets.

## Top-Level Layout

| Path | Role | Notes |
| --- | --- | --- |
| `app.py` | Flask orchestrator and API gateway | Owns Signal Studio API surface, runtime state, config editing, coordinator tasks, legacy controls, Socket.IO. |
| `config.py` | Global Pydantic settings | Reads `.env` and environment variables. |
| `frontend/` | Signal Studio source | React 18, Vite, Ant Design, Recharts, TipTap. |
| `static/signal-studio/` | Built Signal Studio assets | Generated by `npm run build` from `frontend/`. |
| `templates/index.html` | Flask shell for Signal Studio | Loads built JS/CSS from `static/signal-studio/`. |
| `AgentCoordinator/` | Integrated reasoning orchestrator | LangGraph pipeline, bridge schema, cache artifacts. |
| `QueryEngine/` | Evidence search and stance pipeline | LangGraph structured research plus legacy deep-search flow. |
| `MediaEngine/` | Media-oriented research pipeline | LangGraph paragraph research and summary output. |
| `ReportEngine/` | Report planning, IR, rendering, API Blueprint | HTML, Markdown, PDF renderers and Flask report endpoints. |
| `ForumEngine/` | Legacy forum/log-monitoring utilities | Compatibility APIs remain available around the Signal Studio path. |
| `SentimentAnalysisModel/` | Sentiment and topic model experiments | Multiple model families and datasets. |
| `api_evaluation/` | Provider benchmark | Independent harness that informs runtime configuration. |
| `tests/` | Regression tests | Mix of `pytest` style and `unittest`. |
| `docs/` | Authoritative documentation library | This directory. |
| `Dockerfile`, `docker-compose.yml` | Container deployment assets | Flask app plus PostgreSQL service. |

## Source Modules

| Module | Key Files | Main Concepts |
| --- | --- | --- |
| QueryEngine | `graph/builder.py`, `graph/state.py`, `graph/nodes/*`, `agent.py` | Query planning, search, deduplication, trust scoring, stance classification, social enrichment, coverage loop. |
| MediaEngine | `graph/builder.py`, `state/state.py`, `agent.py`, `tools/search.py` | Report structure, paragraph processing, search-backed media synthesis. |
| AgentCoordinator | `graph/builder.py`, `coordinator.py`, `coordinator_output_schema.py`, `utils/report_bridge.py` | Fan-out/fan-in orchestration, divergence matrix, deliberation, CRAG gap filling, report bridge. |
| ReportEngine | `flask_interface.py`, `agent.py`, `ir/schema.py`, `renderers/*`, `graph/*` | Async report tasks, SSE, Document IR, HTML/Markdown/PDF output. |
| Frontend | `src/App.jsx`, `src/views/*`, `src/hooks/*`, `src/components/*` | Signal Studio shell, API hooks, report editor, evidence views, trace monitors. |

## Runtime State And Generated Files

| Path | Producer | Consumer |
| --- | --- | --- |
| `AgentCoordinator/cache/coordinator_output_latest.json` | `AgentCoordinator._export_coordinator_output()` | Signal Studio, ReportEngine bridge |
| `AgentCoordinator/cache/coordinator_output_<timestamp>.json` | AgentCoordinator | Archive/reference |
| `AgentCoordinator/cache/frontend_feedback.jsonl` | `/api/coordinator/feedback` | Signal Studio Monitor |
| `logs/` | Flask, Streamlit legacy apps, ReportEngine, ForumEngine | UI log APIs, diagnostics |
| `output/` | ReportEngine | Report artifacts, chapter JSON, Document IR |
| `static/signal-studio/` | Vite build | Flask template |
